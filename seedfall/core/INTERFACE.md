# `seedfall/core/` — map

Engine primitives: the save, ids, the clock and its phases. No rules, no Qt.

Generated by `python -m seedfall.tests.maps --write` from each module's own docstring (the first sentence of it); the `maps` suite fails when a module is missing here. Why the pieces are shaped as they are is in [`../INTERFACE.md`](../INTERFACE.md) and [`../notes/`](../notes/README.md).

14 modules.

- `cli.py` — The command line: what `python -m seedfall` (and `play.py`) accepts.
- `clock.py` — The daily tick: everything that happens when time passes.
- `guard.py` — What a broad `except` must do when it catches something it was not for.
- `ids.py` — Identities that survive a restart.
- `llm.py` — Whatever language model happens to be on this machine, behind one call.
- `loading.py` — Loading the chronicle from disk, checking it, and clearing it.
- `rng.py` — Seeded pseudo-random number generation.
- `save.py` — Saving and loading.
- `sectortime.py` — Sector time: the phases of a day that run on the Verge's clock.
- `shiptime.py` — Ship time: the phases of a day that run on the crew's own clock.
- `slots.py` — Named chronicles kept beside the one in play, and what each is at a glance.
- `solid.py` — A very small 3D kit: build solids out of primitives, project them to 2D.
- `state.py` — The game state, and the clock that moves it.
- `util.py` — Formatting and small maths helpers shared by the simulation and the GUI.
